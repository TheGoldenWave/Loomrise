# console-next 工作台视觉系统 v0.8

日期：2026-10-26。状态：配置新布局的本地前端设计记录；验证结论和未验项见[配置新布局首轮报告](../../docs/CONFIG-UI-ROUND1-REPORT.md)。本文件说明 `console-next` 的界面决策，不代表 S2 后端、真实模型、权限服务、索引、发布或云部署已实现。

## 配置新布局

本轮依据[线框预览 v0.2](../../docs/CONFIG-UI-PREVIEW.md)和[配置差距需求](../../docs/CONFIG-GAP-REQUIREMENTS.md)调整现有原型，导航跟进将侧栏分成工作区与专家两个平面。工作区展示专家列表与物料库、模型连接、部署与维护三个既有资源入口；列表名称和“进入”打开专家首页，“去处理”是独立快捷动作。专家侧栏顶部提供“返回工作区”和当前专家选择器，下面按搭建顺序展示首页、知识库、红线、业务办理、对话流程、测试、上线和专家设置，不设分组或第二个专家列表入口。客服应用入口仍在上线页，完整字段仍在专家设置的“更多设置”。工作区不展示上次专家的上下文、待处理或试一试；三个已有资源直达不同于终态候选稿中尚待建设的平台设置聚合。原有页面与资源作用域保留，不增加共享知识。

沿用中性白、浅灰、系统字体和克制蓝主操作。`config-v2.css` 补充本轮壳层、队列、办理卡、测试和上线页面样式，`knowledge.css` 承担问答与核对工作面。没有外部图片或字体请求；XLSX 浏览器解析新增本地安装的按需依赖，见[版本钉第 9 节](../../VERSION-PINS.md#9-配置后台前端原型表格解析器2026-10-26)。

侧边栏开关位于顶栏最左侧、面包屑之前，使用与参考截图相同语义的侧栏面板线框图标。桌面端收起时隐藏整条侧栏并将内容区扩展到左侧，开关仍可见；再次展开恢复 208px 侧栏。偏好在工作区、专家页及刷新后保留。手机端沿用同一顶栏位置打开导航抽屉，抽屉状态独立于桌面偏好，点击关闭、选择页面或 Escape 可退出。

顶栏只保留一处“本地交互原型”标识，保存状态显示“已自动保存”或“保存失败 · 重试”。保存失败保留当前页面内容，并提供重试和导出路径。保存只写当前浏览器；草稿错误不拦编辑和自动保存，待处理队列与上线页说明后果。

首页空态提供“放资料、核对、试一试”三步入口；有资料后显示一个“现在先做”、四项文字汇总和最近改动。知识库默认按问答逐条展示，关键信息和标准话术是并列入口，资料视图保留来源管理。核对页按风险分组，不一致时给出人工选择；授权按批填写，默认不勾选。关键信息修改前列出引用处，允许排除个别引用。

红线区分可编辑的“我的红线”和只读“平台底线”。一项业务办理用一张卡说明要问客户什么、确认要求、办成标志及失败和结果不明的处理方式。成功、失败、结果不明分别显示；试办结果由本地脚本记录，不显示为真实接通。

对话流程使用原生 HTML 与 SVG 展示节点和连线，节点直接写“开始、判断、办理、回复、转人工”。流程图和列表共用 `routeGraph`，用表单结构化添加分支；“显示红线”和“显示实际走向”默认关闭。流程问题带定位或补出口动作，不把校验结果写成通用画布或运行引擎已实现。图宽超过可视区时，在图下方显示右箭头作为延续提示；滚动区域可聚焦，左右方向键移动画布，节点仍可按 Tab 访问。

专家平面的“试一试”和“依据”共用右侧位置，同一时间显示一个面板。试一试呈现一轮脚本答复和一行依据；“答错了”进入统一待处理，可转为待人工核对的测试题。依据按“从哪来、哪一版、谁改的、影响谁、凭什么”展示当前本地记录，标识和字段路径收进技术详情。待处理队列区分“上线前必须处理”和“建议处理”，专家导航、首页、专家列表行摘要和上线页共用其来源。

测试页保留人工复核，变差题由人选择“答案错了”或“测试题过时了”。上线页分别提供“发到测试环境”“申请上线”和“回到上一线上版”；申请后仍需单独人工确认。这里的测试环境、入口绑定和回滚均是浏览器内模拟。整组核对、关键信息同步和流程批量操作提供 10 秒撤销；后续配置修改使旧撤销失效。

## 前轮设计记录

以下保留截至 2026-10-15 的 v0.6 设计与验证记录。四组导航、16 路由首层展示、三档深度切换和旧知识工作面已由上节的新布局替代；旧截图数量和通过结论只覆盖当时工件。本轮验证不沿用这些计数，见[配置新布局首轮报告](../../docs/CONFIG-UI-ROUND1-REPORT.md)。

### 视觉世界与尺度

前轮沿用首轮工作台已认可的 Apple-inspired 中性白与浅灰底色、系统字体和克制蓝主动作。使用者在专家配置、客服接待和交付验收任务中操作，因此采用紧凑后台尺度，没有营销式大标题、指标卡或外部图片、字体。

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 编辑、表格与预览内容 |

| `--surface-warm` | `#fbfbfd` | 侧栏与轻量容器 |
| `--fg` / `--fg-2` | `#1d1d1f` / `#424245` | 主文本与次级文本 |
| `--muted` | `#68686f` | 辅助说明、占位文字、元数据 |
| `--border` / `--border-soft` | `#d2d2d7` / `#e5e5ea` | 控件与内容分区 |
| `--accent` / `--accent-hover` | `#0071e3` / `#0066cc` | 当前主操作与焦点 |
| `--success` / `--warning` / `--danger` | `#247348` / `#825e13` / `#b4232f` | 有文字含义的状态 |

字号采用固定尺度，正文行高 1.5，辅助说明 1.55–1.6。段落说明保留约 70 字符的阅读宽度；数据表格按信息量伸展。使用 SF / 系统中文字体回退，只有代码与实际标识使用等宽字体。表格与版本数字使用 tabular numerals。

### Shell 与对象归属

本轮确认一级展示收敛为四组：配置与资料、客服应用、运行与验收、版本与设置。业务概览和专家配置归于专家列表下，选中专家后显示带专家名称的嵌套二级入口；当前子页高亮、父级标示归属，面包屑可返回专家列表。创建仍是专家列表动作。保留16条路由和原对象作用域，选专家先到业务概览；概览与完整配置读取同一草稿，不建立第二套配置库。这是原型导航决定，不替代正式领域合同。

侧栏常驻“当前专家”范围。未选择专家时明确提示从列表打开或新建；链接可达，由页面给选择引导，不使用真实权限徽标假装后端授权。全局连接与部署设置保留自己的归属。

顶部显示当前对象页、专家切换和唯一常驻“本地交互原型”环境标识。配置上下文保留专家、草稿修订、历史版本或草稿状态、保存状态，以及业务概览 / 业务配置 / 详细配置切换。具体模拟操作就近披露边界。保存表示当前浏览器草稿持久化，不表示批准或发布；失败给重试保存动作。只读开关明确为本地界面预览，不代表真实权限服务。

桌面内容区与右侧预览／Agent 协助预留最多两栏，右侧内容用 tab 切换；配置模块索引在内容区内横排，避免形成常驻第三栏。正文按任务分区、紧凑列表与表格组织。容器使用细边界，无装饰性阴影；阴影只用于导航抽屉、提示等覆盖层。

人工创建、编辑、试用和验收是完整主路径。协助入口标为“创作助手（后续）”，仅说明未来使用用户自带外部创作助手的受限接入、提供任务描述复制与折叠的候选差异演示。本轮不运行平台内智能体或工作进程，不提供生成聊天；接入方式仍待实现，用户无需选择运行框架。

概览首层只突出当前最重要缺口与一个主动作，稳定摘要放在具名折叠中。配置十模块以缺项、待确认、可用、可选文字显示状态；空/无效选择首次定位缺口后固化，编辑不自动跳到下一模块，用户可显式选择“优先补齐”。目录保持横排换行，不挤成第三常驻工作栏。

运行、案例、改动候选和连接采用列表/详情/表单互斥工作面。摘要行直接显示状态、版本/来源、不可用原因和详情入口；完整事件、真值、差异及诊断进入详情。返回保留筛选、滚动与发起行焦点；取消不写入数据。连接不提供前端凭据输入，云交付保持向导，不虚构实例集合。

### 组件与状态

共用按钮、表单、checkbox、徽标、提示、空状态、表格、配置索引、就绪检查、来源信息、聊天、Inbox、Widget、联系页、候选差异、证据时间线与部署步骤样式。

主动作使用同一蓝色按钮，次动作白底细边界，辅助动作透明底，危险操作带明确动作名称与低饱和红色。普通、hover、active、focus、disabled、busy、错误与空态都有确定表达。错误说明包含问题和恢复动作；缺口列表保留文字及直达入口，颜色不承担唯一含义。

表单默认标签上置，长说明位于控件下方；支持 `.field-row` 的横排紧凑布局。原生控件保持熟悉行为，复选框不继承文本输入宽度。语义 label、键盘焦点、跳过导航入口和状态提示配合视图提供无障碍基础。

候选差异明确旧值／新值，协助所在窄侧栏使用纵向差异并按需展开。候选仅用于本地交互演示，不能证明真实 Agent 连接或生成已经成功。来源、模拟状态、版本关系和本地持久化由视图数据提供，样式不推断验证结果。客服试用的用户、助手、系统消息分开呈现；人工占用状态和请求终态仍由界面数据分别表达。

### 响应式与动效

| 断点 | 结构变化 |
|---|---|
| ≤1200 px | 侧面板收至 296 px，带侧栏内容的双列表单收为单列 |
| ≤1023 px | 对象导航变为可关闭抽屉，保留遮罩和关闭按钮，主区取消侧栏占位；主要交互区增至 44 px |
| ≤800 px | 编辑 / 预览 / 协助切换一次显示一个工作面板，使用 `ui.mobilePanel`；表单值仍由同一草稿 state 保存 |
| ≤599 px | 顶栏折行、标题动作换行、Inbox 单列、表单恢复单列、版本差异与证据时间线竖排 |

表格默认在自己的容器中横向滚动，保留标题、列关系与全部数据，页面不产生整体横向溢出。适合列表化的表格可显式加 `.mobile-list` 并提供 `data-label`，窄屏转为带标签的行。内容长文本允许换行；按钮名称保持完整。

仅为状态变化提供 180 ms 过渡，抽屉的移动表达导航进入与离开。没有页面进入编舞；`prefers-reduced-motion` 关闭动画和滚动过渡。原生滚动条保持平台行为；选择、插入光标与键盘焦点从同一颜色系统派生。

### 验证范围

已复核最终集成桌面与手机截图，保持旧版灰白、系统字体和紧凑后台尺度。本批三项修复均为 **resolved**：Widget 安装状态与 Inbox 归属／请求状态使用对齐的 key/value 行；概览欢迎语预览按内容收紧；分区标题旁的“管理全部来源”等动作保持完整文案，手机按空间换行。手机协助面板截图已稳定，未再出现导航抽屉停在过渡中途的情况。该结论只覆盖这批修复，不作为全产品视觉评分。

布局检查用 [layout-check.js](tests/layout-check.js) 记录 16 个路由在桌面 1440 × 960 与手机 390 × 844 下的 32 个视图，检查 `document.documentElement.scrollWidth <= innerWidth`，本次未出现页面级横向溢出。表格内部横向滚动保留列关系，不算页面溢出。截图前重新加载最新模块并关闭截图期间的过渡。这里不声明其他尺寸均通过；静态截图不替代键盘、动态恢复或真实服务测试。

完整交互验收由本轮实施报告记录，包含长文案、配置区与面板切换、当前作用域、空状态、disabled 与只读、表格容器和键盘焦点。该检查只证明本地前端布局与交互；真实模型答疑、业务执行、发布权限和云交付仍需独立实现与验收。Agent 协助仍为后续接入预留，历史版本只读与当前草稿编辑共用配置权威，不从前端开关推断真实授权。

### 独立物料库

物料作为知识域独立列表，类型、状态与检索筛选集中于列表上方；详情按原件/派生版本、简介、处理、发布和修订记录呈现。录入是可选业务操作，不增加初始化必经步骤。可人工写简介和完整配置权限；自动处理只给候选，人工审阅仍有独立动作。

人工会话选择器在 Inbox 内保留当前上下文，完成选择与发送分开；历史附件卡片展示固定版本和简介。Agent 自动发送测试折叠放置，默认关闭策略，按需展开；不增加在线创建助手或平台 Worker。处理失败、文件缺失和撤回有明确恢复说明。图片/视频/文档预览保留真实原件与模拟候选的区别，手机转单列并保持完整操作文案。

物料扩展检查覆盖有内容的桌面/390px列表、选择器与图片预览；与全路由两视窗检查一起记录在[交付报告](../../docs/S2-FRONTEND-ROUND2.md)。

### 访客文件体验

试用台与 Widget 使用同一访客对话组件，各自保存会话。输入与附件查看为主路径，技术追踪折叠；文件索取不要求 FAQ 前置。图片可查看大图，视频内嵌播放并可打开大播放器，文档卡片提供正文/PDF查看与原件下载；模拟派生不显示假文件操作。

卡片分别显示本地收件、已打开和已发起下载；不显示真实送达/已解决。新消息跟随聊天底部，编辑输入保留阅读位置。手机 Widget 先展示访客预览再展示后台设置，所有附件动作和输入保持可达。已检查桌面、390px实际两入口、图片/视频/文本以及浏览器 PDF 页面；证据以[本轮报告第 8 节](../../docs/S2-FRONTEND-ROUND2.md#8-访客物料试用与-widget-预览扩展)为准。


### 知识域工作面

知识资料与物料库共用列表/详情/编辑任务结构和 library.css，保持各自对象权威。知识视图独立到 views/knowledge.js，surfaces.js 保留兼容导出。列表把内容、当前可用性和操作放在首层，重复本地说明收为轻量提示；完整来源授权、版本、处理与管理进入具名折叠区。

FAQ默认显示问题和标准解答，长文提供三行预览和完整展开；手机把状态与操作并排放在内容下方。表单的内容与授权有明确分隔，必填输入不藏进折叠。物料范围联动保留选中值，工作区范围不显示无效指定专家选项；高级发送与版本策略仍完整可达。

新工作面聚焦标题，返回聚焦发起行并恢复列表位置。重复折叠使用稳定对象ID键，类型tabs支持方向键/Home/End。原件预览保持背景inert、父页面Tab循环和关闭后的按钮焦点返回。检索结果仅作为当前专家/配置下的临时检查，不跨专家或修订沿用。

本次桌面/中屏/手机的30个知识域视图与既有32个路由视图均检查无页面横向溢出，行为验证见[报告第10节](../../docs/S2-FRONTEND-ROUND2.md#10-知识资料与物料库工作区优化)。
