## 原方案

以场景为工作区，七个分区挂在场景之下：

| 分区 | 页面 | 旅程 |
|---|---|---|
| 场景 | 场景概览、场景包向导、接入与沙盒 | 建 |
| 试用 | 试用台（文字 / 语音） | 试 |
| 运行 | 运行记录、提名与坏例标注 | 看 / 标 |
| 验收 | 案例集（golden / pending / blind）、回放报告 | 验 |
| 改动与发布 | 候选与审批、发布与灰度、策略档位 | 改 / 批 / 发 / 滚 |
| 内容库 | 限制、业务知识、物料、变量、示例片段 | 支撑 |
| 交付 | 导出包与依赖清单 | 交付 |

**首页落点**：场景概览。有未处理事项时，概览页顶部出现「待我处理」区块（待确认提名、待审批候选、观察期状态）。S2 不做跨场景收件箱首页——单场景 alpha 下它是重复入口。
