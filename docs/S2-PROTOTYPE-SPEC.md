## 1. 首轮范围

覆盖专家列表、列表内新建专家向导、专家版本列表、版本详情的人设／流程／边界、试用台、运行记录、案例集、回放验证、案例标注、人评与修正、审批收件箱、改动详情、版本与发布。专家概览与流量、平台知识和设置完整版后续补齐。「新建专家」只作为专家列表主操作，向导虽有独立路由但不占菜单。当前原型按岗位能力显示可进入的菜单；新岗位尚无工具与规则，仅保留专家与版本配置入口。规划范围仍以[信息架构](S2-IA-NAV.md)为准。

原型统一放在 [`prototypes/s2-console/`](../prototypes/s2-console/)；其中 `index.html` 只列页面导航，实际产品入口为 [`screens/experts.html`](../prototypes/s2-console/screens/experts.html)。CSS 与 JS 位于同目录下的 `prototype/`，所有页面同源共享本地状态。使用 HTTP 服务预览，避免 file:// 的浏览器存储隔离。预览无需安装依赖。

## 2. 视觉和交互合同

- Apple-inspired 中性白／浅灰工作面，SF Pro Display／Text 与 SF Mono；蓝色只用于主动作与焦点，不复刻 Apple 品牌资产。
- 侧栏按交付与验证／治理／平台分组，从唯一 routes 数组派生；不让旅程变成一级菜单。
- 页头保留专家上下文；课程样例流程条为建、试、看、改、验、批、滚；新岗位只显示当前可用的建、改入口。
- 桌面侧栏 + 内容面；1024px 以下折叠导航；600px 以下表格转卡片、双栏转单栏、操作换行。44px 操作区，键盘焦点可见，减少动态效果偏好生效。
- 独立页面保留 expert、version 查询参数。稳定／最新指针直接指向具体版本，不引入独立指针页面。
- 草稿自动保存仅写浏览器本地状态，不代表生效；保存失败显式提示。提交冻结，拒绝后派生新草稿；发布只允许已批准且有当前证据的版本。
- 修改草稿使旧回放失效；原型回放只执行原创虚构案例的确定性断言，不调用模型，不用它证明真实质量。
- 两栏证据（不退步／有改善）永久分离。首轮没有真实 blind 评估，改善栏显示缺证据，发布门禁阻断。本地回放不伪造 Gate 通过。
- **排版 Token 规范**（2026-10-13 重定）：`prototype/styles.css` 的 `:root` **只保留 Apple 中性色板与系统字体栈**（`#ffffff`／`#f5f5f7`／`#1d1d1f`／`#6e6e73`／`#0071e3` 等，色彩与字体不含排版尺度），字号、行高、间距、圆角、控件与表格一律按**数据密集型后台**重定——不再沿用营销站的 56／80px 标题、100px 分节间距、1024px 容器与 1.47 行高。基准 4px 网格（`--space-half`…`--space-8`）、7 级字号阶梯（`--text-micro` 11px … `--text-page` 20px）、三级行高、桌面控件 32px。字段标签与输入同行；卡片内常驻说明折进「说明」折叠块；页头描述收起后挂到标题旁 `?` 提示，信息不删除。**只改排版尺度，不改可见性门禁、字段、权限与证据逻辑**；≤1023px 一律回到 44px 操作区与单列表单，触控目标不降级。原型入口页 `index.html` 是落地页不是配置后台，保留展示型排版。

## 3. 专家域设计复盘（2026-10-12，本轮已调整）

- **入口重复**：原型同时在侧栏、页头和流程条放「新建专家」，造成菜单层级误判。现将侧栏仅保留「专家」，流程条「建」回到专家列表，列表页主按钮进入创建向导。
- **列表缺任务信号**：原列表将岗位、场景与版本指针平均铺开，又加一整块泛化「继续交付」，单专家时空白很多，下一步也没有绑定具体岗位。现改成紧凑列表：岗位名与场景在同一单元，稳定／最新版本直达，草稿状态写在最新版本旁；可按岗位或场景查找，无结果有回退提示。
- **创建过程缺复核与回退**：原向导只有「第 N 步／3」，二步勾选把资料授权与规则可裁决性合并，刷新或返回时容易失去中途填写。现以有名称的进度条、两项独立确认、自动保留输入与创建前摘要呈现；修改资料引用后需重新确认授权。创建结果仍仅为本地草稿，不等于来源验证或正式发布。新岗位不继承课程咨询的字段、知识与试用脚本；缺少工具和规则时，试用会明确提示暂不可用。
- **版本页出现伪导航（2026-10-13）**：此前把尚未实现的「概览」「流量」显示为灰色 tab，且唯一可用的「版本」也占一个 tab，让人误以为页面未加载完整。原型现只展示可用的版本列表；专家层面包屑不再错误地显示某个版本号。存在草稿时，页头直接提供「继续编辑草稿」；概览和流量仍保留在规划文档中，完成后再加入导航。

视觉上沿用当前中性底色、蓝色主操作、44px 控件与既有输入系统；这轮只收紧专家域的标题、列表密度与向导宽度。完整 S2 向导中的结果字段、示例结果及版本 diff 仍属后续规划，本地原型不假装已完成。未改变后续真实授权、审批和发布机制的规划状态。

## 4. 最小字段规格（原型，不是正式 API）

| 面 | 字段 | 类型／校验 | 默认与来源 | 生命周期 |
|---|---|---|---|---|
| 人设 | role、goal | 非空字符串，分别 ≤60／500 字 | 虚构成人课程咨询岗位 | 草稿可写；提交后只读 |
| 人设 | tone | 枚举：清晰克制／亲切专业 | 清晰克制 | 同上 |
| 人设 | fields | 字段数组；id 唯一；来源枚举：用户提供／工具返回 | course、time、confirmed | 唯一定义点 |
| 内部数据 | model | default／gpt-6-sol／gpt-6-luna | 本地脚本不读取；原型不提供选择器 | 待真实模型接入 |
| 流程 | steps | 有序字符串数组，至少两步 | 澄清需求、说明课程、确认预约 | 草稿可排序；引用不复制字段 |
| 流程 | exit | 非空字符串 | 明确拒绝即停止推进 | 随版本冻结 |
| 边界 | knowledge／tools／rules | 只读引用摘要 | 原创虚构资料与沙盒工具 | 不开放未决字段编辑 |
| 标注 | expected、must、forbid | 期望状态枚举 + 非空动作文本 | 不预填系统归因 | 存为待审案例，非自动审定 |
| 人评 | relevance、clarity、evidence、expression | 1–5 整数，四项必填 | 不预填 | 保留运行引用 |
| 人评 | correction、reason | 修正文案与理由成对必填 | 空 | 仅建议与留痕，不直接修改内容库 |

技术数据形状见 [`prototype/contracts.ts`](../prototypes/s2-console/prototype/contracts.ts)。本轮不创建正式 HTTP 写接口，K1–K6 仍需后端协商；不修改 S1 合同或依赖。

## 5. 未决事项及阻断处置

- **A1／Q2／Q3**：locked／mutable 和表达层免审批未定。沿用所有改动走草稿门禁；人评修正只生成建议，不直接生效。
- **K0 前三问**：禁止擅自落硬规则字段级编辑器。边界只展示现有约束、来源与执行位置；条件编辑入口禁用，待 K0 决策。
- **Q4 与边界权限**：无登录／RBAC／多租户实现，不用角色切换模拟真实权限。
- 配额归属、页面名称、新页命名仍沿用现行文本，不自行改名。
- 真实语音识别／播放、真实回放服务、blind 批次消费、审批／发布／回滚 API 未接入。原型收起语音、blind、批准与发布操作入口；当前发布样例保留稳定 v3，本地回滚仅允许已发布历史中的前一版 v2，并要求确认理由。
- 本地稳定指针变化只是原型交互，不是外部部署成功。真实发布必须读取持久业务结果与外部标识。

### 响应式与键盘补充（已实现，静态及 DOM 验证）

- 920px 以下双／三列内容转单列；600px 以下表格转标签卡片。表格固定列布局，长请求标识、结果标识、字段和消息允许换行，不通过隐藏页面横向溢出掩盖问题。
- 折叠侧栏关闭时不可被键盘聚焦；打开后聚焦关闭入口，Tab 在导航内循环，Escape 或遮罩关闭后恢复菜单按钮焦点。打开状态通过 `aria-expanded` 暴露。
- 导航与操作区保持至少 44px 高；主按钮链接悬停保留白色文字，悬停／按下使用既有 `--accent-active`，避免变亮导致对比下降。白字默认／悬停对比约 4.70／5.57:1。
- 此项未改变草稿、审批和发布权限，也未开放未决规则编辑器。
