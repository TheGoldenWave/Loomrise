## 1. 本轮交付

- 首轮导航改为首页、知识库、红线、业务办理、对话流程、测试、上线与设置；现行工作区/专家两平面导航见第 6 节。旧深链接保留并归属到新入口。移除配置深度 tabs 与可见“保存草稿”，本地变更即时自动保存，只有存储失败时提供重试。
- 首页有资料冷启动三步；专家列表使用状态、入口、待处理和下一步列。待处理由结构化校验路径与对象状态汇总，顶栏、侧栏红点、首页、列表、上线页共用 `pendingItems()`。
- 知识库以问答为默认工作面，保留关键信息、标准话术和按资料看；批量支持 CSV/TSV/TXT/Markdown/XLSX 的本地解析、批次授权（不默认勾选）、风险分组、冲突裁决、低风险抽检与 10 秒撤销。XLSX 使用动态导入的 `@e965/xlsx@0.20.3`。
- 关键信息集中管理并可引用；红线区分可编辑“我的红线”和只读平台底线，旧转人工短语迁移为红线对象并保持幂等。
- 业务办理以单项表单展示客户入参、确认、办成标志和三态结果；“试办一次”仅记录本地模拟结果，成功/失败/结果不明分开，不生成外部结果 ID。
- 旧线性流程迁移为一份 `routeGraph` 草稿数据；图/层级列表双视图、多判断与汇合路径、分支筛选、意图和例句编辑、结构化加分支、转人工出口、批量红线与确认、节点详情和上线前非阻断校验均已实现。旧步骤和策略表单改为同一工作面的入口；兼容动作同步图与旧字段投影，保留稳定步骤的人工保护。
- 测试页提供最近五次状态和“变差”决策；上线页区分测试快照、申请、人工本地确认与上一版入口回退。页面动作只影响当前浏览器中的模拟版本与绑定。
- 七个专家一级工作面共用“试一试/依据”侧栏；答错进入统一队列并可转为待人工复核的测试题。知识、办理、流程节点、修改记录均有依据入口。
- 老草稿首次覆盖保存前，原始 JSON 自动备份到独立本地键；备份失败不覆盖原记录，设置中可导出副本。批量撤销绑定操作后的修订，后续编辑使旧撤销失效，避免恢复整份快照时丢掉新内容。
- 测试快照必须真正运行已人工复核的脚本测试题；“答案错了”在改稿后持续阻断，当前版本回放通过才解除。申请与最终确认重验测试题签名、来源与连接，旧版本回退也不恢复已撤回授权。
- 更新浏览器术语检查，并增加可重跑的真实点击脚本；来源工作面的原测试仍单独保留。表单单选恢复、上传弹层关闭、流程展开重绘与手机侧栏关闭均包含在本轮修复中。

## 3. 复现

在仓库根目录安装并启动仅本机预览：

```bash
rtk npm --prefix prototypes/console-next ci
rtk proxy python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/console-next
```

打开 [本机预览](http://127.0.0.1:8765/)。在另一个终端，以 `prototypes/console-next` 为工作目录执行：

```bash
rtk npm test
rtk npm run test:browser
rtk npm run test:navigation
rtk npm run test:sidebar
rtk npm run check:terms
```

浏览器检查使用已安装的 Playwright CLI skill 包装脚本；展开收起使用独立 `sidebar-collapse` 会话，其余使用 `config-ui-round1` 会话，均与用户预览分开。安装位置不同时用 `PLAYWRIGHT_CLI` 指定路径。脚本仅创建虚构的本地核验专家，不读私有材料。原型依赖本地安装的 XLSX 模块，不能只复制 HTML/CSS 后宣称同等解析能力。
