## WP5 副作用意图首片

`loomrise/durable_store.py` 将 schema 升至 v6，新增 `tool_attempts`。写工具进入执行适配器前，先把具体动作、参数摘要和绑定该动作的稳定幂等键写入 SQLite；键复用到不同动作/参数会拒绝。确定失败可显式记为 `failed`；成功结果通过原 `commit_write` 路径与业务幂等记录、事件和 outbox 一起提交，并将意图原子转为 `succeeded`。

超时、Run 收尾时仍有未决意图、或重启时旧 Run 被判中断，会将意图转为 `reconciling`。相同幂等键再次请求不会重放工具，而是要求先对账。参数仅持久化哈希，避免把工具参数副本扩散到新表。此实现没有在该记录上自动查询外部系统，也没有把对账结果收敛回业务账本；因此未知状态可以被区分并安全阻断，但 `M-A-07` 所要求的对账出口尚缺。

证据：`tests/test_durable_side_effects.py` 覆盖并发连接竞争（恰有一个执行资格）、重复意图拒绝、参数重绑定拒绝、进程重启后转 `reconciling`、新 Run 对同操作键仍不得再次执行；`tests/test_durable_transaction_crashes.py::test_v5_to_v6_tool_intent_migration_rolls_back_and_retries` 覆盖 v5→v6 DDL 迁移回滚与重试。2026-10-29 全量后端 `unittest discover` **128/128**，另执行 S1、合同语义、语音通道/配置自检与固定案例回放 **11/11**，均通过。
