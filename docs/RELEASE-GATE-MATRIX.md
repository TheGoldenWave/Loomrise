## 0. 四条登记纪律

1. **一行一条 Gate，不合并。** 一条 Gate 含多个子项（例如"重启恢复、去重、撤回"）时拆成多行，否则无法判"部分通过"。
2. **工件必须是可复核物**：测试用例、录制件、报告、清单、导出包。文档段落、原型截图、演示视频不算工件。
3. **状态只有四值**：`未开始` · `在跑` · `通过` · `不通过`。"有数据""看过一遍"不进状态列，只进备注。
4. **证据分两层**（`runs/` 已被 `.gitignore` 忽略，不能当唯一凭据）：**原始件**留本地 `runs/<版本>/`；**入库摘要**写 `docs/reports/<版本>-EVIDENCE.md`，每条 Gate 一段，必须含样本量、环境、语料版本、未覆盖项。本表"证据位置"列填**摘要锚点**（如 `R0-EVIDENCE.md#m-s1-13`），原始件名写在摘要里。
