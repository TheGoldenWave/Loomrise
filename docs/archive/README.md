## 归档规则

1. **以明确替代或结束为条件**。时间旧、研究性质或仍待决策不是归档依据；现行证据、活动计划和仍在使用的原型保留。
2. 完整失效方案可移入 `docs/archive/<主题>/`；部分失效只提取该节。归档文件保留原内容，并标记来源、版本、归档日、失效范围与后继。
3. 原入口保留简短后继指针。移动时修复历史文件的相对链接与引用它的入链；不要删掉原始结论或改写过去的测试结果。
4. 归档不等于删除或确认后继提案。后继尚待定稿时明确其状态；不能根据归档操作宣称实现或验收完成。
5. 历史快照原则上只修链接与事实性勘误；新方案写回现行专题。每次变化同步本目录索引与文档总索引。
6. 私有资料继续按开源边界存放在本地工作区，不搬到公开历史目录。
