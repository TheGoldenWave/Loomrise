# RELEASE-PLAN 评审处置台账 v0.1

## 0. 处置口径

- **采纳**：按意见改了文档，且能指出改动位置。
- **部分采纳**：结论方向对，但意见的事实前提或落点需要修正；改的是修正后的版本。
- **不采纳**：写清理由与替代处置。**不采纳不等于没听见**，替代处置必须落在文档里。
