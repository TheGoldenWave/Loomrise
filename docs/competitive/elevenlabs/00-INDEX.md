## 4. 三条贯穿全卷的结构性差异

写在各卷开头会重复，所以只在这里说一次。**这三条决定了"能不能照抄"**：

1. **它把"配置"当第一公民，把"裁决"当组织流程。**
   `AgentVersion` 是不可变快照（这点与我们同构），但"哪个分支上线""能否合并"交给**分支保护 + 提案审批**——而合并**不要求测试通过**（官方把"测试通过才能合并"列为未来能力）。→ 差异不在版本机制，在**门禁位置**。

2. **它的编排以"LLM 可理解的自然语言"为默认，确定性是可选第二形态。**
   Procedures 的触发条件、Workflow 的边条件，默认都是自然语言（`LLM Condition`）；确定性表达（`Expression` 构造器 + 表达式 AST）存在、完整、但**不是默认**。→ 我们"条件只能引用已声明字段"是可以产品化的，但要自己把默认反过来。

3. **它的"记忆"是会话级注入 + 一个未文档化的 per-agent 开关，没有独立的记忆对象。**
   KB 有 `Memory (Alpha)` 页签（agent 级、仅日期过滤）；per-agent 设置表里 `privacy` 含 "user memories"，**语料中 0 篇独立文档**。→ 不要拿它做"记忆体系"的参照；它的记忆是**配置的附属**，我们的记忆是**候选与证据**。

## 6. 本目录的维护规则

- **新增事实** → 写进对应卷的事实表，并**回标证据等级**。

- **语料失效** → 重新抓取后比对篇数与 `llms.txt` 索引；篇数变化 >5% 时在 §3 语料地图更新并在本文件顶部改抓取日。
