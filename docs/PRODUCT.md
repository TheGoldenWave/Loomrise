# 产品定义 v0.1

状态：探索，2026-09-26。名称暂定 Agent Workbench（目录代号，不是品牌定名）。

## 用户与价值主张

首位用户是**业务 PM／运营**，希望不依赖研发完成业务 Agent 的初版搭建、网页试用、坏例定位和受控迭代。个人创作者和团队均可单机试用；企业服务端规模化是后续验证方向。

> 从一份可用的业务资料开始，完成“冷启动 → 文字/语音试聊 → Trace → Badcase → 改动候选 → 回放验证 → 人工发布/回滚”，并让非工程人员看懂为什么变好、代价是什么。

核心优势不是能接最多模型或画布节点，而是**首次可用时间、运行可解释性、改动有证据**。宣传时严格区分演示指标和已验证生产指标。

## 第一条黄金路径

1. 用户选择「售前客服 + 线索预约」场景包，上传原创/有权使用的 FAQ、服务边界、预约字段和人工转接条件。
2. 系统生成版本化 `AgentSpec` 草稿；用户审阅可更改规则与锁定规则、知识来源、工具白名单。
3. Web 文字与网页语音分别试聊；两条链共用同一业务配置、线索字段、策略和 `Run` 关联，语音另保留录音授权、打断、播放回执等媒体事件。
4. 用户选择坏例并标注原因；系统或人提出局部 `ChangeProposal`，展示来源 Run、变更 diff、作用域和风险。
5. 使用固定样本与红线规则回放旧版和候选版；评测结果由独立规则/人工复核，用户批准、灰度或拒绝，且可恢复旧版。

## 模拟场景包

- **原创虚构在线课程咨询**：课程适合对象、时间安排、疑问澄清、预约顾问。虚构品牌与价格；不从雇主或第三方系统复制任何素材。
- **原创虚构二手车咨询**：车型信息、车况问题的证据/不确定性表述、预约看车或回电。车型、用户和线索均为模拟。
- 保险、牙科、医美可以列作扩展模板，但首先只允许**一般信息与预约/人工接管**，不做诊断、疗效、产品收益、资质或价格承诺。没有真实合作关系，不可用虚构数据声称真实转化结果。

## 成功指标（待基线实测，不预写达标结果）

- 业务用户从导入场景包到第一次可用试聊的耗时；完成率与求助次数。
- 文字与语音各自的可用性、语音首响/打断恢复/误播、线索字段正确率与转人工正确率。
- Run 的配置版本与知识/工具引用覆盖率、坏例归因可解释性、固定集前后效果及单位成功任务成本。
- 受限改动通过率、回滚成功率、关键安全红线零漏过（目标，而非当前事实）。

## 非目标与边界

不做通用 CRM、任意用户自助外呼、全功能节点画布、自动修改生产安全规则、训练自有大模型、未授权数据摄入、为其他项目重建长期个人记忆系统。Web 语音与 PSTN 电话是不同交付阶段。

**独立性**：本项目是业务 Agent 配置/运行/评测/发布的权威；GoldenWave 仅可能提供经治理的长期 Context Pack，不运行或编排本项目 Agent。工作经历只能抽象为公开方法，不能移植私有代码、Prompt、数据或品牌。
