## 0. 四条登记纪律

1. **父 Gate 与证据细化分层登记。** 一条 Gate 含多个独立验收子项时可拆行；`M-A-19…21` 与 `M-C-11…12` 明确标为细化行，不增加父 Gate 的数量或独立退出判据。
   **但分层不是免责**：父行转 `通过` 之前，其名下所有细化行必须是 `通过` 或 `不适用`（写明理由）；父行的"证据位置"必须**引用细化行**，不能只写自己的锚点。**严禁父行已通过而细化行长期停在 `未开始`**——那正是本表当初要消灭的"自我认证"。
2. **工件必须是可复核物**：测试用例、录制件、报告、清单、导出包。文档段落、原型截图、演示视频不算工件。
3. **状态只有四值**：`未开始` · `在跑` · `通过` · `不通过`。"有数据""看过一遍"不进状态列，只进备注。**唯一例外**：细化行可用第五值 `不适用`（机制未采用，例如未选用 checkpoint），且必须在该行写出理由；父 Gate 行不得使用。
4. **证据分两层**（`runs/` 已被 `.gitignore` 忽略，不能当唯一凭据）：**原始件**留本地 `runs/<版本>/`；**入库摘要**写 `docs/reports/<版本>-EVIDENCE.md`，每条 Gate 一段，必须含样本量、环境、语料版本、未覆盖项。本表"证据位置"列填**摘要锚点**（如 `R0-EVIDENCE.md#m-s1-13`），原始件名写在摘要里。
