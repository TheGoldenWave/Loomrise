# Loomrise 命名决策与备选记录

**2026-09-26 决定采用 Loomrise**，本地目录及拟建 GitHub 仓库统一使用 `Loomrise`。现有个人项目名如 **GoldenWave、Malow、LifeSub、Follow-up**：短、可独立记忆，既能承载产品故事，也不过度绑定某个技术框架。沿用“一个词 + 一句明确副标题”的方式。

| 候选 | 释义 / 气质 | 适配的副标题 | 取舍 |
|---|---|---|---|
| **Loomrise** ★ 已选 | loom 编织多渠道的运行证据，rise 表示持续改善；与 GoldenWave 等命名一样偏意象化 | `Build agents. Learn from every run.` / 让每次运行成为下一次改进 | 正式项目名；需要副标题解释 Agent 属性。粗略公开搜索未发现明显同名 Agent 平台，**不代表商标/域名可用** |
| **Runloom** | Run + loom，每次运行织成版本与经验 | `From run to better agent.` | 功能指向最准确，但已有其他领域同名 GitHub 仓库，公开发布前应查重 |
| **Casegrove** | Case 坏例与 grove 生长，突出可验证迭代 | `Grow better agents from real cases.` | 很适合坏例→改进的传播主线；稍长，且已有其他行业同名实体 |
| **AgentTide** | Agent 的进退、灰度和版本潮汐，呼应 GoldenWave | `Agents that improve with evidence.` | 好理解但更泛化，区别于现有 Agent 品牌的辨识度需再确认 |
| **星织 / Starweave** | 编织业务规则、渠道和反馈，中文友好 | `从冷启动到可信自迭代` | 中文传播可用；英文潜在重名与文化语感待查 |

已统一项目名与本地目录；尚无包名或域名。未做商标、全网产品名和域名尽调，不能宣传为“名称已可注册”。
