# Agent Workbench（暂定工作目录，产品名未定）

> **状态：产品探索 / 文档仓库。** 尚无可运行应用、已验证技术栈或公开服务。名称候选见 [命名备选](docs/NAMING.md)。

为**业务 PM 与运营**设计的 Agent 冷启动及可验证自迭代工作台：从原创或获授权的业务资料生成 Agent 配置，在网页端以文字和语音试用，追踪每次运行，把坏例转为可审阅的改动提案，再经过回归验证、人工审批与回滚。

**一句话边界**：本项目拥有业务 Agent 配置、跨渠道运行证据与版本发布；现成的 Agent 框架、语音媒体栈和观测平台通过 Adapter 接入。不是 Dify/Octop 的整体 fork，也不是雇主内部系统的开源版。
