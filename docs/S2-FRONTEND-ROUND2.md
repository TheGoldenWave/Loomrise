# 第二轮配置后台前端交付与评审说明 v0.6

状态：2026-10-15，**本地可交互前端已实现；各批次实际验证范围分别记录，本轮导航/布局优化及未验辅助技术Gate见第11节；S2 后端服务仍未实现**。没有接入真实 AI、MCP/Skills 桥接、渠道或云，也没有改变 S1 代码与依赖。旧[首轮原型](S2-PROTOTYPE-SPEC.md)保留对照。

入口：[第二轮页面](../prototypes/console-next/index.html)。当前运行地址为 `http://127.0.0.1:8788/console-next/`，仅限本机。重新启动可在仓库根目录运行：

```text
rtk proxy python3 -m http.server 8788 --bind 127.0.0.1 --directory prototypes
```

只需浏览器和静态服务，无新增前端运行依赖。直接打开 HTML 文件不保证 ES modules 可加载，请通过 HTTP 预览。草稿/元数据仅保存在该浏览器的 localStorage，物料原件缓存到 IndexedDB；换浏览器不会自动同步；“已保存”不代表已保存到服务端。

## 1. 本轮采用的范围

以[体验优化需求](CONFIGURATION-UX-OPTIMIZATION.md)为输入，落实人工配置优先、业务概览与详细配置共用草稿、先资料答疑再接工具。最新取舍如下：

- **完整人工路径是主流程**：填写名称即可建立草稿；目标、服务对象和复杂字段可后补。答疑不要求先配置预约或业务写工具。
- **Agent 协助是后续接入预留**：面板仅提供目标/修订/授权来源元数据、受限任务说明复制和可折叠的虚构候选差异审阅。不提供聊天助手、自动建造或后台作业界面，不建设平台内 Worker。
- 后续用户自己的 Agent 可按[外部接入计划](AGENT-INTEGRATION-PLAN.md)参与创建与迭代。桥接尚未实现，网页不显示“已连接”或要求初次用户选择框架；人工路径不依赖外部 Agent。
- 保留候选基准、来源、实际字段差异、人工保护、校验和版本绑定，为后续受限 Agent 介入提供共同界面；前端合同不是正式服务 API。

Task、长期记忆/画像、电话与多租户等独立建设计划不在本轮实现范围。新增客服应用配置面不意味着 Knocket 完整服务覆盖已经通过运行验收。

## 2. 页面与人工操作

本轮有 **16 个路由视图、13 个一级导航入口、选中专家后的2个二级入口、10 个配置模块**；新建专家由列表动作进入，不占导航。沿用中性灰白、系统字体与克制蓝主操作；桌面两栏编辑/预览，小屏按工作面切换。原六个对象域上增加“客服应用”，这只定义该轮前端落点，不把整体 IA 的旧页数改写成已定稿。

| 视图 | 可以体验的操作 | 范围 |
|---|---|---|
| 专家列表 | 搜索、选择专家、继续配置、进入手动创建 | 本地对象管理 |
| 新建专家 | 填写名称/目标/对象，查看后续 Agent 协助方式，刷新或返回保留中途输入 | 两种说明入口共用同一人工表单，创建后不自动弹助手 |
| 业务概览 | 服务摘要、资料、动作、分项就绪、下一步和外观预览 | 读取同一草稿，不新建隐藏 Prompt |
| 业务/详细配置 | 接待回答、资料、流程、字段、Skill、约束、动作、结果、模型预算、版本依据 | 业务词优先；来源、机器 ID 和六层关系按需展开 |
| 知识资料 | FAQ、URL、File 登记/修订，来源授权、有效期、阶段、重试、撤回与详情 | 本地 FAQ 与文本实际接收；抓取/复杂解析未接入 |
| 物料库 | 录入图片/视频/文档、原件预览下载、简介审阅、授权范围、处理候选、发布撤回与检索策略 | 原件实际浏览器缓存；压缩/理解/自动发送见第 7 节 |
| 客服试用 | 访客提问/索取物料、附件收件与查看，资料内/资料外/人工/取消，快照与运行 | 答疑/检索用固定脚本；原件实际浏览器读取，见第 8 节 |
| 人工 Inbox | 本地模拟访客、接管、人工文字/附件回复、释放与 Agent 自动发送测试，区分接待占用与业务请求 | 不给外部访客发送消息；新增物料流程见第 7 节 |
| Web Widget | 外观配置、独立访客对话、索取/收件/查看附件、表单/FAQ/预约外链和安装诊断 | 当前草稿本地体验；示例安装代码不可运行，见第 8 节 |
| 联系页 | 模板、四类受约束块增删/排序/编辑、预览、版本绑定与停用 | text/FAQ/chat/link；未发布公网页面 |
| 运行记录 | 来源定位、未解决问题直达人工出口配置、坏例/提案提名 | 本地记录，非服务端 RunEvent 权威 |
| 案例与回放 | 人工填写/修订/审定真值，行级脚本回放，版本失效提示 | 不替代正式 EvalSet 或真实质量门禁 |
| 改进提案 | 起草限定字段差异，模拟配对比较、采用/拒绝、失效与人工保护 | 真值/案例或草稿变化必须重验，不直接上线 |
| 版本与发布 | 本地结构检查、明确批准、冻结版本、绑定入口、只读历史、恢复为新草稿 | 保存、批准、冻结/绑定分开，全部为本地演示 |
| 模型连接 | 无密钥的连接声明，分项成功/失败模拟，引用与撤销 | 不调用供应商；不构成协议支持矩阵 |
| 部署与维护 | 资源与数据流步骤、失败/重试、备份恢复/升级说明 | 不创建云资源，不提供 Worker 设置或真实备份 |

现有确定性规则只读，未决条件合同明确说明；工具仅登记模拟策略。完整 `ToolManifest` Schema、规则算子/冲突模型和服务权限要按既有合同决策细化，不能从此页面推定后端已支持。

## 3. 已实现的共同交互边界

1. 人工编辑、概览、详细视图和候选采用写入同一草稿；冻结版本保留独立快照。保存草稿不会改变已绑定版本。
2. 人工字段默认受保护；步骤/字段重排与删除按稳定对象 ID 迁移保护标记。过期候选不能覆盖新值，采用按实际字段留存旧值、新值与提案来源。
3. FAQ 同题不同答案出现冲突时，具体原因与资料修复入口可见，脚本试用/批准阻断；不自行选择第一份口径。
4. 资料撤回使后续匹配与有关入口可用性失效；历史配置仍可查看，恢复旧配置不恢复被撤回授权。
5. 本轮试用冻结快照，取消和配置改变阻止迟到回复；生成、送达、解决保持不同事实。所有本地答复仍不证明真实问题解决。
6. 改稿使旧案例回放待重验；案例/真值变化使候选比较失效，采用前再核对固定案例签名。
7. 文件读取冻结专家/表单和读取代次，切换/二次选择使旧读取失效；文件读取失败保留草稿。知识文本当前限 500 KB、50000 字，不隐藏截断；物料缓存采用独立的 50 MB 前端演示上限。
8. 损坏或不兼容的本地记录暂停自动保存；显式重试保存先保留恢复副本，不用示例覆盖原文。普通配额失败保留内存草稿并提示导出/重试。
9. 只读是前端预览模式，历史冻结版本不能写入；它不构成真实身份、RBAC 或多租户隔离证据。
10. 中文输入法、表单中途值、展开状态、键盘导航、Escape 关闭和小屏面板切换均纳入交互处理。

## 6. 后端交接与下一轮评审

前端状态与 [FRONTEND-CONTRACT](../prototypes/console-next/FRONTEND-CONTRACT.md) 是协作投影，正式 API 应在应用服务边界设计，不能直接照搬 localStorage 对象或相信客户端校验。

| 后端工作面 | 页面已经表达的输入与必要结果 |
|---|---|
| 草稿与版本 | 身份/作用域、基准 revision、结构化 patch、幂等、来源与采用；返回权威版本与差异，不覆盖发布版 |
| 资料摄入 | 范围/授权/有效期、真实解析/索引作业、重试/取消/撤回、引用版本与影响，隔离二次选择/迟到产物 |
| 连接与试用 | 服务端凭据引用、实际协议/流式/工具/取消检查、预算、冻结快照、ServiceRequest/RunEvent与结果证据 |
| 物料交付 | 独立资产/授权/版本、对象存储和真实产物、经审简介索引、渠道文件限制、ToolPolicy/占用重验、幂等与回执对账 |
| 客服会话 | 访客/坐席身份、消息送达、接管占用代次、暂停确认与恢复，不用通知或静默替代业务结果 |
| 案例与候选 | 真值权限、固定 EvalSet 快照、旧/候选配对结果、受影响证据失效，独立 Gate、批准与发布 |
| 页面/入口 | 受约束应用 Schema 与独立页面版本、指定 AgentVersion 绑定、真实 SDK 与加载/请求/事件/送达证据 |
| 外部 Agent | 复用同一应用服务的 MCP/Skills/API，受限草稿/候选及来源读取，客户端兼容性独立验收；本轮不做 Worker |
| 云交付 | 发行版本、资源/费用与外部数据流、授权创建、恢复/升级/回退实测；不可把本地流程完成当部署证据 |

先由用户在页面上评审命名、默认值、字段必要性、详细模块容量、关键确认和操作顺序，再冻结前端能力定义与正式合同。后端建设继续遵循[验证路线](ROADMAP.md)；仍未通过的 S1 Gate、K0 规则形状、真实媒体/渠道与支持矩阵保持开放，不被此次前端实现关闭。

## 7. 物料库与 Agent 自动发送扩展

2026-10-14，**前端已实现并验证；后端规划未实现**。能力定义见[物料专题](MATERIAL-LIBRARY-AND-DELIVERY.md)，协作状态见[物料前端合同](../prototypes/console-next/MATERIALS-CONTRACT.md)。

- 知识域新增独立物料库，业务可手动录入图片、视频和文档，维护名称、简介、标签、用途、来源/授权、有效期、专家范围与发送权限。上传和处理不自动改写知识答疑资料。
- 原件实际存入 IndexedDB，元数据保存在 localStorage；支持原件预览/下载与跨刷新恢复。图片/视频压缩只登记无真实文件的模拟候选；简介建议只按元数据产生明确标记的候选，业务可直接人工填写并审阅。
- 人工 Inbox 支持纯附件或文字加附件。Agent 自动发送默认关闭，同时需要物料自动发送许可和当前草稿策略；检索已审简介与标签，按优先原件/模拟派生候选及显式回退、数量上限（本地 1–5）选择。测试的访客索取是操作员模拟输入，消息冻结请求依据、策略、文件修订与简介。
- 发送前检查物料发布/审阅/授权/日期/范围、具体版本、专家/会话/占用代次与实际原件，异步校验后再重验。转人工、撤回、过期、旧修订或旧代次阻断新发送；失败保留文字与选择，历史附件不随后续修订改变。
- 文件上传/核验冻结上下文和文件引用；失效上传解除旧保存状态，旧核验不能覆盖替换原件的可用性。损坏物料记录保留原文并进入存储恢复路径。展开面板在输入重渲染时保持展开。

## 8. 访客物料试用与 Widget 预览扩展
