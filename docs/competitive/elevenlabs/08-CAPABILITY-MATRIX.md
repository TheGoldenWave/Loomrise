# 08 · 能力对照矩阵（查漏用，不作结论）

> 用途：**逐维度查漏**。看到"他有我无"就去总纲看是否已登记；看到"我有他无"就确认这条是不是我们的差异化点。
> **本卷不产生判断**：不评优劣、不建议采纳。采纳/不采纳只写在总纲 §8 / §9。
> 证据：本卷所有"他有"均来自卷 01–07 的事实表；所有"我有"只引用我方**已有文档**的结论，不新造。

**状态列说明**
- `他有我无` — 它有能力，我方文档未定义。
- `我有他无` — 我方文档已定义，它没有对应物。
- `形态不同` — 双方都有，但抽象层级或默认值相反。
- `双方都缺` — 都没有，或都只到半成品。
